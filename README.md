# Tauri Plugin Review

A Tauri plugin for requesting in-app reviews on Android using Google Play's In-App Review API.

## Installation

### 1. Add the Plugin to Your Tauri Project

Place the plugin in your project structure:
```
your-tauri-app/
├── src-tauri/
│   └── Cargo.toml
└── tauri-plugin-review/  (this plugin folder)
```

### 2. Add Dependency to Your Tauri App

In your `src-tauri/Cargo.toml`:
```toml
[dependencies]
tauri-plugin-review = { path = "../tauri-plugin-review" }
```

### 3. Register the Plugin

In your `src-tauri/src/lib.rs` or `main.rs`:
```rust
fn run() {
    tauri::Builder::default()
        .plugin(tauri_plugin_review::init())
        .run(tauri::generate_context!())
        .expect("error while running tauri application");
}
```

### 4. Configure Permissions

In your `src-tauri/capabilities/default.json`:
```json
{
  "permissions": [
    "review:allow-request-review"
  ]
}
```

### 5. Install the JavaScript Package

From your frontend directory:
```bash
npm install --save file:../tauri-plugin-review/guest-js
```

Or add to your `package.json`:
```json
{
  "dependencies": {
    "tauri-plugin-review-api": "file:../tauri-plugin-review/guest-js"
  }
}
```

## Usage in Your App

```typescript
import { requestReview } from 'tauri-plugin-review-api';

// Show review dialog after positive user action
async function handleReviewRequest() {
  try {
    await requestReview();
    console.log('Review dialog shown');
  } catch (error) {
    console.error('Could not show review:', error);
  }
}

// Best practices: Show after positive user interactions
// - User completes a task successfully
// - User reaches a milestone
// - After several successful uses of the app
// Don't show on first launch or too frequently
```

## Important Notes

1. **Google's Quota Limits**: Google limits how often the review dialog can be shown to users. It may not appear every time you call it.

2. **Testing**: During development, the review dialog may not appear consistently. Test on a real device with your app installed from the Play Store.

3. **Best Practices**:
   - Only request reviews after positive user experiences
   - Don't show on first app launch
   - Don't show immediately after installation
   - Space out requests (wait weeks/months between requests)
   - Never interrupt critical user flows

4. **Android Only**: This plugin currently only supports Android. On other platforms, the command will return an error.
